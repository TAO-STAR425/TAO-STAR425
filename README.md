## Hi there 👋
# ⛏️ TAO Miner at a glance
- I’m a TAO miner who loves keeping rigs stable, efficient, and looking good.
- Obsessed with squeezing more TAO per watt and sharing what works so others can level up faster.

# ⚙️ Current setup (upgraded)
- Hardware: 3× RTX 4090 rigs (9 GPUs total) + 1× 3080 backup node, tuned for 24/7 uptime with undervolt/OC profiles.
- Stack: Ubuntu 22.04, nvidia-driver 550 + CUDA toolkit; systemd + PM2 for process management; Grafana + Prometheus + node_exporter for metrics.
- Pool/Validator: Mining on a low-latency EU community validator endpoint.

# 📈 Performance snapshots (example values with upgrade)
- Avg rate: ~920 kH/s
- Uptime: 99.7% (7d)
- TAO earned (7d): ~18.6 TAO
- Efficiency: ~0.028 TAO/kWh

# 🛠️ What I’m improving now
- Lowering watt/TAO with smarter power profiles and gentle overclocks.
- Faster alerting for temps, stale shares, and downtime.
- Trying alternative endpoints for lower latency.
